# Unified Biomedical Knowledge Graph (UBKG) 
<br>

# Versions of the UBKG System

---

There are two different versions of the [UBKG System](/about/system). Although the versions have similar representations of biomedical data, 
they have different data models and solution architectures.

## [UBKG-JKG](../../ubkg-jkg)
The current version of the UBKG system is built around a JSON source file in [JSON Knowledge Graph (JKG)](https://github.com/x-atlas-consortia/json-knowledge-graph) format.
The UBKG-JKG system is used to build distributions of the [Data Distillery implementation](/about/implementations/cfde-data-distillery)
released from 2027.

## [UBKG-CSV](../../ubkg-csv)
The original version of UBKG system was built around a set of CSV extracts of UMLS data.
The UBKG-CSV system was used to build implementations of 
* [Petagraph](../implementations#petagraph)
* [Data Distillery](../implementations#cfde-data-distillery) prior to 2027
* [HuBMAP/SenNet](../implementations#hubmapsennet-ontology)
