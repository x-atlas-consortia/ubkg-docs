# Unified Biomedical Knowledge Graph (UBKG) 
<br>

# UBKG Extraction, Transformation, and Load (ETL)

---

The [UBKG system](../system) is used to build an instance of UBKG from a collection of biomedical sources.

The _Extraction, Transformation, and Load_ (ETL) workflows build the [import files](../system#import-files) 
that Deployment workflows import into an instance of UBKG. The form of ETL workflow depends on
the version of the UBKG system.
