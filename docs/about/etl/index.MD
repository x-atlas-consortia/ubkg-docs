# UBKG Extraction, Transformation, and Load (ETL)

The [UBKG system](../system) is used to build an instance of UBKG from a variety of biomedical sources.
The _Extraction, Translation, and Load_ (ETL) process used to build the [import files](../system#import-files) for a UBKG instance depend on
the version of the UBKG architecture ([UBKG-CSV](../../../ubkg-csv) or [UBKG-JKG](../../../ubkg-jkg).)
